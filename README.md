# Industrial Coil AI

## Goal

This project aims to model the manufacturing process of industrial electrical coils and to build a synthetic dataset for Machine Learning applications.
It is inspired by a real industrial manufacturing process. The synthetic dataset is generated from a simplified process model and does not contain confidential production data.

This project includes:
- process modelling;
- synthetic data generation;
- exploratory data analysis;
- predictive models;
- anomaly detection;
- explainability.
